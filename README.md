# IloTech Studio — site de l'agence marketing

Site vitrine de l'agence marketing d'IloTech : réseaux sociaux, contenus créés avec l'IA, publication automatique,
automatisation (CRM, devis, factures), assistants IA.

- `index.html` : la page unique du site (HTML + CSS intégrés, aucun outil à installer)
- `img/` : images (logo, photos)
- Publication : GitHub Pages (dépôt `ilotech97x/agence-marketing`), adresse prévue `https://studio.ilo-tech.com`

Les prix viennent de la grille IloTech (data.js du site principal) : les garder identiques.
